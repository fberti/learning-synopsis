   Monotonitás definı́ciója: Az (an ) : N → R sorozat
 • monoton nő, ha minden eleme nagyobb(=), mint az előző: ∀n ∈ N : an ≤ an+1 ;
 • monoton csökken, ha minden eleme kisebb(=), mint az előző: ∀n ∈ N : an ≥ an+1 ;

   Korlátosság definı́ciója: Az (an ) : N → R sorozat
 • alulról korlátos, ha egy adott számnál (alsó korlátnál) minden eleme nagyobb(=):
   ∃Ka ∈ R : ∀n ∈ N : Ka ≤ an ;
 • felülről korlátos, ha egy adott számnál (felső korlátnál) minden eleme kisebb(=):
   ∃Kf ∈ R : ∀n ∈ N : an ≤ Kf ;
 • korlátos, ha alulról és felülről is korlátos.

                                     Határérték és műveletek
    Műveletek a bővı́tett valós számok (R = R ∪ {−∞, +∞}) körében:
      ∀x ∈ R : x + ∞ = ∞                      ∞+∞=∞                      ∀x ∈ R : x/∞ = 0
      ∀x ∈ R : x − ∞ = −∞                     −∞ − ∞ = −∞                ∀x ∈ R : x/ − ∞ = 0
      ∀x > 0 : x · ∞ = ∞                      ∞·∞=∞
      ∀x > 0 : x · (−∞) = −∞                  −∞ · (−∞) = ∞
      ∀x < 0 : x · ∞ = −∞                     ∞ · (−∞) = −∞
      ∀x < 0 : x · (−∞) = ∞                   −∞ · ∞ = −∞
    Jegyezzük meg, hogy a következő (ún. kritikus értékek) nincsenek értelmezve:
                                                        x     ±∞
                               ∞ − ∞, 0 · (±∞),           ,
                                                        0     ±∞
   A határérték és műveletek kompatibilitásának tétele: Legyenek (an ) és (bn ) olyan
