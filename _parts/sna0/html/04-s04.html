0.4 A könyv adatkészletei Pythonban ★

Most már tudod, hogyan áll egy háló egy CSV-ben, és mire figyelj betöltéskor. Ideje a valódi adatoknak. A kurzus módszertani leckéi két lépésben gyakoroltatnak: előbb a könyv példáját futtatod újra a könyv adatán, és a kinyomtatott számmal veted össze, aztán a saját hírkorpuszodra viszed át. Ehhez az első lépéshez kellenek a könyv adatai, Pythonban.

Útiterv:

  1. Honnan? A könyv R-csomagja, és miért nem a CRAN-ról jön.
  2. Az adatprojekt szerkezete: hálók, attribútumok, metaadat egy helyen.
  3. Export R nélkül: az rdata csomag és egy 80 soros szkript.
  4. Mi van benne, és mi hibás benne? A 26 adatkészlet áttekintése.

1. lépés: honnan jönnek az adatok?

Az ASNR saját R-csomagra épül, az xUCINET-re. Ez tartalmazza a könyv függvényeit (xDensity(), xDegreeCentrality() …) és az összes adatkészletét. A könyv 5.4.1. szakasza szerint install.packages("xUCINET")-tel telepíthető. Ez ma nem működik: a csomag nincs a CRAN-on.

A könyv csomagja: xUCINET 0.0.2.0020

A könyv weboldala (sites.google.com/view/asnr-2022/xucinet) szerint a csomag sem a CRAN-on, sem a GitHubon nem érhető el. Egy .tar.gz fájlként tölthető le: ez az aktuális xUCINET_0.0.2.0020.tar.gz (2022. szeptember), mellette ott az előző, 0.0.1.0022. Töltsd le a projekted data/raw/ mappájába. Parancssorból (2026 novemberében ez a link működött):

mkdir -p data/raw
curl -L -o data/raw/xUCINET_0.0.2.0020.tar.gz \
  "https://drive.usercontent.google.com/download?id=1gGEGHq5z_Nrm1uPROXxUmuX-p4uibPKt&export=download&confirm=t"

A fájl egy tömörített R-forráscsomag: R/ (a függvények), man/ (a súgó) és data/ (52 .rda fájl). Nekünk csak a data/ kell.

Buktató: két csomag, hasonló névvel
  • A GitHubon van egy xucinet (kisbetűvel, stephenborgatti/xucinet, 2.0-s verzió, 2026 szeptembere). Ez a könyv 2. kiadásához készült, a nulláról újraírva. A README szerint nem kompatibilis a 0.x-szel: más függvénynevek, más adatkészletnevek (pl. padgett, hightech). A kurzus a 2022-es (1.) kiadást követi, ezért a 0.0.2.0020 kell.
  • Az install.packages("xUCINET") hibaüzenete („package 'xUCINET' is not available”) nem a te hibád: a csomag tényleg nincs a CRAN-on.

2. lépés: az adatprojekt szerkezete

Egy adatkészlet ritkán egyetlen mátrix. A Padgett-adatban két háló van (házasság, üzlet), plusz a családok vagyona, és egy leírás arról, mi mit jelent. Az ASNR (5.4.1) ezért mindent egy adatprojektbe gyűjt.

Kiinduló eset: a Padgett-projekt 
Padgett_FlorentineFamilies
├── ProjectInfo     leírás, attribútumok és hálók magyarázata, hivatkozások
├── Attributes      16 × 4 táblázat: NodeName, Wealth, Priors, Degree116
├── NetworkInfo     hálónként: név, mód, irányított?, értéktípus
├── Business        16 × 16 mátrix (üzleti kapcsolat)
└── Marriage        16 × 16 mátrix (házassági kapcsolat)

R-ben ez egy list, amelynek az elemei mátrixok és data.frame-ek. Pythonba olvasva egy szótár lesz belőle: a mátrixok xarray.DataArray-k (sor- és oszlopcímkékkel), a táblázatok pandas.DataFrame-ek.

Adatprojekt

Egy vizsgálat összes hálója, attribútuma és metaadata egy objektumban: ProjectInfo (szöveges leírás, kódkönyv), Attributes (csúcsattribútumok), NetworkInfo (hálónként: Name, Mode, Directed, Values …), és a hálók a saját nevükön. Miért jó? Egyben marad, ami összetartozik: a mátrix mellett ott a kódkönyve. Ellenőrizni is lehet, hogy minden háló és az attribútumtábla ugyanazokra a csúcsokra, ugyanabban a sorrendben vonatkozik-e.

Mi lesz ebből nálunk? Fájlszinten egy mappa adatkészletenként (data/asnr/Padgett_FlorentineFamilies/), benne hálónként egy CSV, egy attributes.csv, egy networkinfo.csv és egy info.json. Pythonban egy DataProject objektum (0.6), amely ezt a mappát egy lépésben betölti.

3. lépés: export R nélkül

A kurzusterv eredetileg egy „egyszeri R-lépést” írt elő: R-ben betölteni a csomagot, és onnan CSV-be menteni mindent. Kipróbáltuk, és van egyszerűbb út. Az .rda fájl az R saját, dokumentált bináris formátuma, és a Python rdata csomagja olvasni tudja. Kiegészítés.

Az exportszkript: scripts/asnr_export.py

Ugyanez mind az 52 fájlra, CSV-be mentve. A lényeg három függvény:

  • to_frame(x): egy R-mátrixot (DataArray) címkés DataFrame-mé alakít;
  • export(name, obj): egy adatprojekt minden részét a saját fájljába írja (<Háló>.csv, attributes.csv, networkinfo.csv, info.json);
  • main(tarball): végigmegy a tömörített fájl data/*.rda tagjain, kicsomagolás nélkül.
uv run python scripts/asnr_export.py data/raw/xUCINET_0.0.2.0020.tar.gz
Kész: 52 adatkészlet -> data/asnr/
A teljes szkript 
"""Az ASNR (xUCINET 0.0.2) összes adatkészletének exportja CSV-be – R nélkül."""
import json
import sys
import tarfile
from pathlib import Path

import numpy as np
import pandas as pd
import rdata

OUT = Path("data/asnr")


def to_frame(x):
    """R-mátrix (xarray.DataArray) vagy data.frame -> pandas DataFrame, címkékkel."""
    if isinstance(x, pd.DataFrame):
        return x
    labels = [x.coords[d].values if d in x.coords else np.arange(n) + 1
              for d, n in zip(x.dims, x.shape)]
    return pd.DataFrame(np.asarray(x), index=[str(v) for v in labels[0]],
                        columns=[str(v) for v in labels[1]])


def plain(x):
    """ProjectInfo -> JSON-ba írható szerkezet."""
    if x is None:
        return None
    if isinstance(x, dict):
        return {str(k): plain(v) for k, v in x.items()}
    if isinstance(x, pd.DataFrame):
        return x.astype(str).to_dict(orient="records")
    return [str(v) for v in np.atleast_1d(x)]


def export(name, obj):
    folder = OUT / name
    folder.mkdir(parents=True, exist_ok=True)
    if not isinstance(obj, dict):                 # ábraadat vagy sima táblázat
        to_frame(obj).to_csv(folder / f"{name}.csv")
        return
    for part, x in obj.items():
        part = str(part)
        if part == "ProjectInfo":
            text = json.dumps(plain(x), ensure_ascii=False, indent=2)
            (folder / "info.json").write_text(text, encoding="utf-8")
        elif x is None:
            continue
        elif part == "Attributes":
            to_frame(x).to_csv(folder / "attributes.csv")
        elif part == "NetworkInfo":
            to_frame(x).to_csv(folder / "networkinfo.csv")
        else:
            to_frame(x).to_csv(folder / f"{part}.csv")


def main(tarball):
    n = 0
    with tarfile.open(tarball) as tf:             # a csomagot ki sem kell csomagolni
        for m in tf.getmembers():
            if m.isfile() and "/data/" in m.name and m.name.endswith(".rda"):
                parsed = rdata.parser.parse_data(tf.extractfile(m).read())
                for name, obj in rdata.conversion.convert(parsed).items():
                    export(str(name), obj)
                    n += 1
    print(f"Kész: {n} adatkészlet -> {OUT}/")


if __name__ == "__main__":
    main(sys.argv[1])

4. lépés: mi van benne, és mi hibás benne?

Az alábbi táblázatot a saját exportunkból generáltuk. Az „irányítatlan / irányított” oszlop az adatból számolt (szimmetrikus-e a mátrix), nem a metaadatból. Hogy miért, az a táblázat után derül ki.

Adatkészlet (csomagbeli név)HálókMéretAz adat szerintÉrtékekAttr.Lecke

„Vegyes”: a projekt egyik hálója szimmetrikus, a másik nem. „Lecke”: ahol a kurzusterv használja; a „–” jelűek a könyv gyakorlófeladataihoz kellhetnek. A könyv adatlistájában szerepel még a Johnson PolarStation és négy közösségimédia-adat (Everett: Hollywood, Reddit, Sunbelt, YouTube). Ezek nincsenek a 0.0.2-es csomagban.

A metaadatok hibái (kipróbálás közben találtuk)
  • Wolfe_Primates: a NetworkInfo szerint a Kinship háló irányítatlan (Directed = FALSE), de a mátrix nem szimmetrikus: 15 nyíl, egyik sem kölcsönös (szülő → utód irányban kódolva).
  • Borgatti_Camp92, Baker_Journals, Mainas_Terro: a NetworkInfo nevei nem egyeznek a hálók neveivel (Borgatti_Campnet_MostInteractionsT2 ↔ MostInteractionsT2; Citations ↔ CoCitations; a Mainas-adatnál Distance ↔ Contact).
  • Mainas_Terro, Borgatti_Scientists960: az attribútumtábla mérete eltér a hálóétól (4 614 sor a 4 275 csúcshoz, illetve 504 sor a 960 csúcshoz). Címke szerint kell illeszteni, és a 960-as hálónál a csúcsok fele attribútum nélkül marad.
  • Padgett_FlorentineFamilies: a NetworkInfo oszlopnevei mások (NetworkName, ModeSender … a többi projekt Name, Mode … oszlopai helyett). Az info.json hálóleírásai elcsúsztak: a „Business” mellett az áll, hogy „marriage alliances”. Az attribútumtáblában a családnév oszlop (NodeName), a sorok címkéje pedig 1–16.
  • Knecht_Class12b: hiánykódok a hálókban (9, 10) és az attribútumokban (−99); néhány átlóelem sem 0.
  • Rehnquist_SupremeCourt: a leírás szerint 0/1 („a többséggel szavazott-e”), de 32 cellában 0,5 áll, és 9 cella hiányzik (NaN).
Hüvelykujjszabály Az adat a mérvadó, a metaadatot az adatból ellenőrizd. Hogy irányított-e egy háló, azt a mátrix szimmetriája mutatja meg, nem egy TRUE/FALSE felirat. Ha a kettő ellentmond, olvasd el a szöveges leírást, és döntsd el tudatosan.
